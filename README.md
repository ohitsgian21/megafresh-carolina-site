# Mega Fresh Carolina — website

The public website for Supermercados Mega Fresh in Carolina, Puerto Rico, served at **[superelmejor.com](https://superelmejor.com)**.

This repository holds only the files the site serves. For a tour of the project, with a video and screenshots, see the [showcase](https://ohitsgian21.github.io/megafresh-carolina-showcase/).

Designed and built by Gianlexis Quiñones. The layout started from an HTML Codex template (see `LICENSE.txt`).
